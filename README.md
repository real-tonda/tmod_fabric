# TMod Fabric

A server-side Fabric mod for Minecraft 1.21.8.

## Features

- Server-side mod structure for Fabric 1.21.8
- Ready for server-side logic implementation

## Building

1. Clone this repository
2. Run `./gradlew build` (Linux/Mac) or `gradlew.bat build` (Windows)
3. The built mod will be in `build/libs/`

## Development

This mod uses:
- Minecraft 1.21.8
- Fabric Loader 0.16.11
- Fabric API 0.100.3+1.21.8
- Java 21
