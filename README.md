# TMod Fabric

A basic Fabric mod for Minecraft 1.21.8.

## Features

- Example block and item
- Basic crafting recipes
- Proper mod structure for Fabric 1.21.8

## Building

1. Clone this repository
2. Run `./gradlew build` (Linux/Mac) or `gradlew.bat build` (Windows)
3. The built mod will be in `build/libs/`

## Development

This mod uses:
- Minecraft 1.21.8
- Fabric Loader 0.16.11
- Fabric API 0.100.3+1.21.8
- Java 21
